# PRD: 提示词优化工具 (Prompt Optimizer)

## 1. 概述

一个跨平台（Windows/Mac）的提示词优化桌面工具。用户选中任意文本后，按快捷键即可快速调用 AI 优化提示词，结果以弹窗形式呈现，支持一键复制。

## 2. 目标

- 提供全局快捷键，快速唤起优化功能
- 支持 Windows 和 macOS 双平台
- 最小化依赖，MVP 先上线
- 可配置的 AI 服务（不锁定具体 provider）

## 3. 用户故事

### US-001: 全局快捷键触发优化
**描述:** 作为用户，我希望按一个快捷键就能唤起优化工具，这样我不需要打开额外窗口就能使用。

**验收标准:**
- [ ] 安装后在系统托盘/菜单栏显示图标
- [ ] 默认快捷键 `Cmd+Shift+P`（Mac）/ `Ctrl+Shift+P`（Windows）可触发
- [ ] 支持在配置文件中自定义快捷键
- [ ] 应用在后台运行时也能响应快捷键

### US-002: 选中文本自动优化
**描述:** 作为用户，我希望选中一段文字后按快捷键，系统就能自动优化这段提示词。

**验收标准:**
- [ ] 快捷键触发时读取系统剪贴板内容
- [ ] 将剪贴板内容发送给 AI 服务优化
- [ ] 显示加载状态（防止用户以为没响应）
- [ ] 优化完成后弹出结果窗口

### US-003: 优化结果弹窗展示
**描述:** 作为用户，我希望看到优化后的结果，并能方便地复制使用。

**验收标准:**
- [ ] 弹窗显示原始提示词和优化后提示词（上下对比）
- [ ] 提供「复制」按钮，一键复制优化结果
- [ ] 提供「关闭」按钮或点击外部关闭弹窗
- [ ] 弹窗居中显示，大小约 600x400px

### US-004: AI 服务可配置
**描述:** 作为用户/开发者，我希望可以配置使用的 AI 服务，这样可以根据需要切换不同 provider。

**验收标准:**
- [ ] 配置文件支持设置 AI 服务类型（OpenAI/Claude/本地等）
- [ ] 支持配置 API Key 和 Endpoint
- [ ] 支持选择使用的模型（如 gpt-4、claude-3-opus）
- [ ] 配置路径：`~/.prompt-optimizer/config.json`

### US-005: 托盘/菜单栏驻留
**描述:** 作为用户，我希望工具在后台运行，不占用任务栏/ Dock 空间。

**验收标准:**
- [ ] 启动后最小化到系统托盘（Windows）/ 菜单栏（Mac）
- [ ] 托盘图标右键菜单包含「设置」「退出」选项
- [ ] 点击托盘图标可打开主设置窗口

## 4. 功能需求

- FR-1: 全局快捷键监听（跨平台）
- FR-2: 读取剪贴板内容作为待优化文本
- FR-3: 调用可配置的 AI API 进行提示词优化
- FR-4: 结果弹窗展示（原始 vs 优化后）
- FR-5: 一键复制优化结果到剪贴板
- FR-6: 系统托盘/菜单栏图标和菜单
- FR-7: 配置文件读写（API 配置、快捷键配置）

## 5. 非目标

- 不做提示词模板/预设管理
- 不做优化历史记录
- 不做多语言界面（先英文）
- 不做自动更新功能

## 6. 技术选型

| 组件 | 选择 | 说明 |
|------|------|------|
| 框架 | Tauri | 轻量、跨平台、原生体验 |
| 前端 | React + TypeScript | 快速开发 UI |
| 后端 | Rust | Tauri 原生支持 |
| AI 调用 | 可扩展 | 默认预留接口，支持对接任意 provider |
| 打包 | Tauri bundler | 自动生成 .exe / .app |

### 推荐的 Tauri 项目结构

```
prompt-optimizer/
├── src/                    # React 前端
│   ├── components/
│   │   ├── ResultModal.tsx  # 优化结果弹窗
│   │   └── Settings.tsx    # 设置页面
│   ├── App.tsx
│   └── main.tsx
├── src-tauri/              # Rust 后端
│   ├── src/
│   │   ├── main.rs
│   │   ├── clipboard.rs     # 剪贴板读取
│   │   ├── hotkey.rs        # 全局快捷键
│   │   ├── ai.rs            # AI 服务调用
│   │   └── config.rs        # 配置管理
│   ├── Cargo.toml
│   └── tauri.conf.json
├── config.json.example     # 配置文件示例
└── package.json
```

## 7. 配置文件的格式

```json
{
  "ai": {
    "provider": "openai",  // or "claude", "ollama"
    "api_key": "your-api-key",
    "endpoint": "https://api.openai.com/v1",
    "model": "gpt-4"
  },
  "hotkey": "CmdOrCtrl+Shift+P",
  "theme": "system"  // "light" | "dark" | "system"
}
```

## 8. 成功标准

- Windows 和 Mac 都能成功打包运行
- 快捷键在后台运行时可正确触发
- AI 服务可配置并正常工作
- 弹窗显示优化结果，复制功能正常
- 应用体积 < 20MB
